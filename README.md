# 🎵 O Mundo da Música

Um site desenvolvido em **HTML5** e **CSS3** com o objetivo de explorar o universo musical, apresentando artistas de destaque e diferentes estilos musicais. O projeto conta com um design moderno inspirado em portais de notícias.

## 🚀 Funcionalidades

* **Página Inicial:** Apresentação geral do site e boas-vindas.
* **Página de Artistas:** Lista com alguns dos principais nomes da música atual (como Baco Exu do Blues, BK' e Rihanna).
* **Página de Estilos Musicais:** Divisão por géneros musicais (Rock, Pop, Rap e MPB) com descrições e imagens ilustrativas.
* **Menu de Navegação Rápido:** Acesso facilitado entre todas as páginas do site.

## 📂 Estrutura de Pastas

```text
/
├── index.html       # Página Inicial
├── pagina2.html     # Página de Artistas
├── pagina3.html     # Página de Estilos Musicais
├── style.css        # Arquivo CSS principal com a estilização
└── imagens/         # Pasta contendo todas as imagens utilizadas

```

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estruturação das páginas)
* **CSS3** (Estilização visual, Flexbox e design responsivo)
